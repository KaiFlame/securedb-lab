# Segurança do laboratório

Somente dados sintéticos, acesso local e ambiente acadêmico. Não publique credenciais, CA privada, dumps ou logs brutos. Não exponha os serviços à Internet usando esta configuração didática.

Falhas devem ser descritas ao responsável pelo repositório com a menor evidência sintética necessária. Não inclua tokens ou dados de terceiros. Consulte `docs/riscos_residuais.md` para limites conhecidos e `docs/github.md` antes de publicar.
